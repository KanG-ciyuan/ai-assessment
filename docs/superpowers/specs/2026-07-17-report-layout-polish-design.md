# 报告页桌面布局优化设计

## 目标

在不改变 V2.0 题库、分数、阶段规则和报告内容的前提下，改善桌面端答题与报告页面的信息密度和图表可读性。

## 调整范围

1. 答题标题在桌面端收紧至 26-36px 范围，减少题目和选项之间的空白。
2. 报告 Hero 缩小最小高度、内边距、总分字号和阶段说明间距，让四维图更早进入视口。
3. 雷达图保持四维数据形状，但将标签定位改为固定的外围锚点：顶部/底部居中，左/右两侧外置对齐；图表左右预留足够文字空间，标签不可覆盖多边形。

## 实现边界

- 仅修改 `index.html` 的 CSS 与 `drawRadar` 标签坐标计算。
- 保持移动端单列样式；桌面端是主要优化目标。
- 保留现有色彩、档案感和内容层级，不引入新组件或外部依赖。

## 验收

- 桌面端题目、四个选项和上一题/提交控制更紧凑。
- 报告顶部不再占据过多首屏高度。
- 左右两侧维度名称均在雷达图外部，四个标签不与图形、数据点重叠。
- 全部既有自动化测试继续通过。
