# V2.1 单次个性化建议设计

## 目标

在 V2.0 固定规则报告不变、默认不消耗模型调用的前提下，为每一份完成的测评结果提供一次可选的短篇个性化建议。它的作用是把固定报告中的优先提升方向，落到用户下一步可以执行的动作上，而不是变成一个无限追问的聊天入口。

## 已确认的产品边界

1. 测评仍为 12 题、4 个维度、固定前端评分；阶段判断、优势、短板和 7 天学习路径仍是报告的主体。
2. 个性化建议位于完整 7 天学习路径之后，采用内嵌面板，不抢占报告首屏。
3. 每一份完成的测评结果可成功获取 1 次建议；用户重新完成测评后，得到一份新结果，可再获取 1 次。
4. 只提供一次性结果解读，没有文本输入框、上下文追问、会话历史、登录、支付、课程或知识库问答。
5. 固定报告必须始终可用。模型 API 未配置、关闭或出错时，不影响测评、评分和固定报告。

## 页面与交互

### 默认状态

在 7 天学习路径后显示“个性化建议”面板。面板说明该功能会根据本次的四维得分和学习路径，补充一条更具体的下一步；本次结果可免费获取 1 次。按钮文案为“获取个性化建议”。

### 加载与成功状态

点击后按钮禁用并显示简洁加载状态，防止普通用户重复点击。成功后面板替换为三段固定结构：

- 当前状态：25 至 70 个中文字符，解释本次能力结构，不复述题目或分数表。
- 下一步动作：40 至 90 个中文字符，把第 1 天动作改写为一个具体任务，并保留目标、场景和完成标准。
- 一个提醒：25 至 70 个中文字符，指出一个容易犯的错误或注意点。

三段内容使用普通段落和固定标题呈现，不渲染模型返回的 Markdown、表格、代码块、Emoji 或自定义标题。页面刷新后直接读取已成功缓存的建议，不再次调用接口。

### 失败状态

- 未启用或未配置密钥：提示“个性化建议暂未开启”，固定报告继续可用。
- 模型或网络异常：提示“暂时无法生成，请稍后重试”，本次资格不扣除。
- 当日额度达到上限：提示“今日个性化建议额度已用完，请明日再试”，本次资格不扣除。
- 已成功生成：再次点击只展示已缓存内容，不再发送请求。

## 客户端与数据流

### 测评结果标识

每次提交 12 道题时生成 `assessmentId`，并与答案、固定评分结果、7 天路径和个性化建议一同保存到现有浏览器本地存储。重新测评必定生成新的 `assessmentId`，即使答案相同也视为新的测评结果。

旧版本地结果没有标识时，前端在读取时补写一个新的 `assessmentId`，保证查看历史结果不会报错。浏览器清除本地数据后，客户端不再保留已生成的建议；服务端仍会对已使用的结果标识实施限制。

### 请求边界

前端只发送 `assessmentId` 与本次 12 个答案至新接口 `/api/personalized-advice`。服务端以 V2 的 `assessment-core.js` 规则重新计算总分、阶段、四维得分、优势、优先维度和第 1 天行动；不信任客户端提交的总分、阶段或模型提示词内容。

旧的 `/api/generate-report` 使用 V1 五维模型和长篇 Markdown 输出，保持停用且不会被新页面调用。V2.1 不修改或复用它的 Prompt、题目映射和数据库写入逻辑。

## 模型提示词与输出契约

### 输入

服务端仅向模型提供以下可信的 V2 结果：

- 当前阶段名称与一句阶段说明；
- 总分和四个维度的名称、得分、状态；
- 已计算出的优势维度、优先提升维度；
- 对应路径的第 1 天行动。

不提供原始题干、用户身份信息、旧版五维数据或任何知识库内容。

### 输出

系统提示词要求模型只返回一个 JSON 对象：

```json
{
  "current_status": "...",
  "next_action": "...",
  "caution": "..."
}
```

提示词禁止 Markdown 标记、列表、表格、Emoji、代码块、额外键、寒暄和“根据测评结果”等套话。参数使用较低随机性，输出 token 上限控制在足以完成三段短文的范围内。

服务端必须解析 JSON 并校验三个字段均为纯文本、非空且长度符合上限。解析失败、字段缺失、字段超长或含有不允许的结构化格式时，接口返回可重试错误，不向页面透传模型原文。

## 成本控制与隐私

### 双层限制

1. 结果级限制：同一个 `assessmentId` 只有在模型成功且内容校验通过后，才被登记为已使用。
2. IP 日限制：按 Cloudflare 的访客 IP 加盐哈希后，以 UTC 自然日统计；同一哈希每天最多成功生成 5 次。

检查或模型调用失败不会消耗结果次数或 IP 日额度。客户端禁用按钮只用于改善体验；服务端的 D1 记录才是实际约束。

### 存储

新增 D1 使用记录表，保存 `assessment_id`、IP 加盐哈希、日期键和创建时间，不保存原始 IP、用户姓名、联系方式或原始答题文本。使用记录保留 7 天，并在后续请求中清理过期记录。

该方案不使用登录或验证码，因此不能在恶意脚本场景下提供严格的“每人一次”保证；它是面向免费公开 Demo 的成本护栏。需要更严格防滥用时，后续版本再单独评估登录、验证码或服务端风控。

## 配置与启用

实现完成后，`AI_ANALYSIS_ENABLED` 默认保持关闭。此时页面只展示固定报告，个性化入口显示为未开启状态，不会发出请求。仅在 Cloudflare 的密钥与 D1 绑定均验证完成后，才允许开启该开关。

正式启用时，在 Cloudflare Pages 配置以下服务端密钥后再打开功能：

- `DEEPSEEK_API_KEY`：新的模型调用密钥；
- `IP_HASH_SECRET`：随机生成的私密盐值，用于不可逆地哈希 IP；
- D1 绑定：供使用次数记录使用。

密钥不写入前端仓库、不出现在浏览器请求、不记录于日志。

## 测试与验收

### 自动化测试

1. 服务端以 V2 题目答案计算四维结果，绝不引用 V1 五维模型。
2. 提示词输入只包含允许的 V2 字段。
3. JSON 校验接受有效三字段对象，拒绝缺字段、额外结构、代码块、Markdown 和超长内容。
4. 同一成功结果在客户端刷新后读取缓存，不触发二次请求。
5. 固定报告和 7 天路径在 API 关闭、未配置密钥和接口失败时均可正常显示。

### 人工验收

1. 完成测评后，可在 7 天路径后看到入口；桌面与移动端不遮挡既有内容。
2. 成功建议不出现旧版的 Emoji 标题、Markdown 分隔线、表格或冗长段落。
3. 同一结果第二次操作不新增模型调用；重新测评后可以得到新的建议。
4. 未配置密钥时，用户收到明确提示而不是空白、报错堆栈或虚假 AI 内容。
5. 配置密钥并启用后，验证模型输出、D1 限制和每日 5 次上限。

## 非本次范围

- 飞书知识库接入、向量检索、RAG 和知识问答；
- 用户聊天、连续对话、上传文件、登录、支付、课程；
- 重写旧 V1 接口或将旧历史报告迁移为 V2；
- 重新设计题库、阶段规则或 7 天学习路径本身。
