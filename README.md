# AI 能力测评

> 一份 12 道题的 AI 应用能力测评，帮助用户判断自己能否把 AI 用进真实任务，并获得下一步行动方向。

**公网地址**：https://ai-assessment-260.pages.dev

---

## 这个产品做什么

很多人对 AI 的了解停留在"ChatGPT 能聊天"，不知道自己能否把 AI 用进学习、生活和工作。网上教程满天飞，但很少有工具能让人看清自己的应用短板。

这个工具希望为普通用户提供一个轻量的自我盘点入口：通过 12 道真实场景题，了解自己的能力阶段、强项、优先短板和七天行动路径。

## 当前状态

- 网站当前为 **V2.0 免费体验版**：基础测评、四维得分、雷达图和七天行动路径可直接使用。
- 计分与报告在浏览器本地按固定规则生成，不会发起模型调用。
- 最近一次结果保存在当前浏览器；清除站点数据后会丢失。
- 后端仍保留 Cloudflare Pages Function 与 D1 结构，但 V2.0 不处理答题请求。

## 功能

- **12 道情境选择题**，覆盖 AI 理解与判断、任务表达与协作、场景应用与问题解决、工具选择与流程能力
- **固定规则报告**，根据四维得分展示能力阶段、优势、优先短板和三步行动建议
- **四维雷达图**，直观看到能力结构
- **本地复测**，最近一次结果保存在当前浏览器
- **纯前端**，答完即出结果，无需注册登录

## 技术栈

| 环节 | 工具 |
|------|------|
| 前端 | 纯 HTML/CSS/JS，零框架，约 3500 行 |
| 部署 | Cloudflare Pages（国内可直连） |
| 数据库 | Cloudflare D1（SQLite） |
| API 层 | Cloudflare Pages Function |
| AI 引擎 | 大模型 API |
| 开发方式 | Vibe Coding（Codex / Claude Code 协作） |

## 架构

```
用户答题 → 前端固定规则计算四维得分 → 立即展示阶段、画像和行动路径

最近一次结果 → localStorage → 刷新后可再次查看
```

设计原则：**轻量、国内可访问、成本可控**。核心测评不依赖模型调用，AI 分析按需启用。

## 开发过程

这个产品从想法到上线，全程用 Vibe Coding 方式完成——自然语言驱动 AI 写代码，在飞书对话框里指挥。

**时间线：**

- **第一天**：写下项目思路文档，确定产品定位
- **第二天**：
  - PRD 定稿 + 12 题题库设计 + 前端三页开发
  - 部署上线 + 数据库建表
  - 方案被墙 → 果断切换 + 接入 AI 分析
  - 调试修复 → 全线跑通
- **第三天**：从旧平台迁移到 Cloudflare Pages + D1，国内手机也可直连
- **第四天**：Codex 重新设计前端，深色极简风+金色点缀

## 遇到的问题

| 问题 | 解决方案 |
|------|----------|
| Supabase 域名国内访问不稳定 | 从 Supabase 方案迁移，保留历史实现记录 |
| Vercel 域名手机端访问不稳定 | 迁移到 Cloudflare Pages，国内可直连 |
| 模型调用成本需要控制 | 当前关闭 AI API，保留基础报告体验 |
| 模型名升级 | 适配最新模型版本 |
| 变量名冲突 | supabase 重命名为 supabaseClient |

## 测评维度

| 维度 | 题数 | 满分 | 说明 |
|------|------|------|------|
| AI 理解与判断 | 3 | 9 | 理解适用边界，并能核验和修正输出 |
| 任务表达与协作 | 3 | 9 | 将模糊需求表达为清晰、可迭代的任务 |
| 场景应用与问题解决 | 3 | 9 | 用 AI 处理学习、生活或工作中的真实问题 |
| 工具选择与流程能力 | 3 | 9 | 根据任务选择工具，并组织多步骤工作过程 |

满分 36 分，阶段划分：认知起步（0-9）、基础协作（10-18）、场景应用（19-27）、流程进阶（28-36）。任一维度低于 4 分时，最高阶段为场景应用。

## 本地运行

这是一个纯静态 HTML，浏览器直接打开就能跑（不连数据库和 API 的情况下）：

```bash
# 用浏览器打开
open index.html

# 或者用 Python 起一个本地服务器
python3 -m http.server 8080
```

飞书知识库陪练属于后续独立版本；当前 V2.0 不接入知识库、登录或模型 API。
