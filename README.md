# AI 能力测评

> 一份 12 道题的 AI 能力体验测评，帮助用户认识能力结构与下一步学习方向。

**公网地址**：https://ai-assessment-260.pages.dev

---

## 这个产品做什么

很多人对 AI 的了解停留在"ChatGPT 能聊天"，不知道自己 AI 能力什么水平、该从哪里学起。网上教程满天飞，但没有一套标准帮人自评。

这个工具希望为 AI 初学者提供一个轻量的自我盘点入口：通过 12 道选择题，了解自己的强项、薄弱点和学习方向。

## 当前状态

- 网站当前为**体验版**：基础测评、五维度得分、雷达图和本地学习路径可直接使用。
- AI 深度分析 API 暂停，结果页会展示基础报告，不会发起模型调用。
- 后端仍保留 Cloudflare Pages Function 与 D1 结构，待完成下一轮迭代和成本保护后再重新启用 AI 分析。
- 无需注册登录；如重新启用 D1，系统仅保存匿名答题数据和报告，不收集姓名、手机号或邮箱。

## 功能

- **12 道选择题**，覆盖 5 个能力维度：AI 认知、使用频率、工具掌握、学习意愿、行业应用
- **基础报告与学习路径**，根据五维得分展示强项、薄弱点和三步学习建议
- **AI 深度分析**，架构已保留，当前维护中
- **五维度雷达图**，直观看到自己的强项和薄弱点
- **学习路径建议**，从"立刻做"到"长期目标"三步规划
- **纯前端**，答完即出结果，无需注册登录

## 技术栈

| 环节 | 工具 |
|------|------|
| 前端 | 纯 HTML/CSS/JS，零框架，约 3500 行 |
| 部署 | Cloudflare Pages（国内可直连） |
| 数据库 | Cloudflare D1（SQLite） |
| API 层 | Cloudflare Pages Function |
| AI 引擎 | 大模型 API |
| 开发方式 | Vibe Coding（Codex / Claude Code 协作） |

## 架构

```
用户答题 → 前端计算五维得分 → 立即展示基础报告与学习路径

AI 分析启用后：前端 → Pages Function → 大模型 API → 返回个性化报告
                                      → 匿名答题与报告写入 D1
```

设计原则：**轻量、国内可访问、成本可控**。核心测评不依赖模型调用，AI 分析按需启用。

## 开发过程

这个产品从想法到上线，全程用 Vibe Coding 方式完成——自然语言驱动 AI 写代码，在飞书对话框里指挥。

**时间线：**

- **第一天**：写下项目思路文档，确定产品定位
- **第二天**：
  - PRD 定稿 + 12 题题库设计 + 前端三页开发
  - 部署上线 + 数据库建表
  - 方案被墙 → 果断切换 + 接入 AI 分析
  - 调试修复 → 全线跑通
- **第三天**：从旧平台迁移到 Cloudflare Pages + D1，国内手机也可直连
- **第四天**：Codex 重新设计前端，深色极简风+金色点缀

## 遇到的问题

| 问题 | 解决方案 |
|------|----------|
| Supabase 域名国内访问不稳定 | 从 Supabase 方案迁移，保留历史实现记录 |
| Vercel 域名手机端访问不稳定 | 迁移到 Cloudflare Pages，国内可直连 |
| 模型调用成本需要控制 | 当前关闭 AI API，保留基础报告体验 |
| 模型名升级 | 适配最新模型版本 |
| 变量名冲突 | supabase 重命名为 supabaseClient |

## 测评维度

| 维度 | 题数 | 满分 | 说明 |
|------|------|------|------|
| AI 认知 | 3 | 9 | 知不知道 AI 能干什么 |
| 使用频率 | 2 | 6 | 日常用不用、用多少 |
| 工具掌握 | 3 | 9 | 用过哪些、用到什么深度 |
| 学习意愿 | 2 | 6 | 愿不愿意学、怎么学 |
| 行业应用 | 2 | 6 | 自己行业有没有 AI 落地场景 |

满分 36 分，等级划分：探索者（30+）、进阶者（20-29）、入门者（10-19）、初识者（0-9）。

## 本地运行

这是一个纯静态 HTML，浏览器直接打开就能跑（不连数据库和 API 的情况下）：

```bash
# 用浏览器打开
open index.html

# 或者用 Python 起一个本地服务器
python3 -m http.server 8080
```

重新启用 AI 报告前，需要在 Cloudflare Pages 中配置 `DEEPSEEK_API_KEY`，绑定 D1 数据库 `DB`，并执行 `schema.sql`。

## 灵感来源
