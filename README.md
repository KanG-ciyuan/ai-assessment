# AI 能力测评

> 一份 12 道题的 AI 应用能力测评，帮助用户判断自己能否把 AI 用进真实任务，并获得下一步行动方向。

**公网地址**：https://ai-assessment-260.pages.dev

---

## 这个产品做什么

很多人对 AI 的了解停留在"ChatGPT 能聊天"，不知道自己能否把 AI 用进学习、生活和工作。网上教程满天飞，但很少有工具能让人看清自己的应用短板。

这个工具希望为普通用户提供一个轻量的自我盘点入口：通过 12 道真实场景题，了解自己的能力阶段、强项、优先短板和七天行动路径。

## 当前状态

- 网站当前为 **V2.1 免费体验版**：基础测评、四维得分、雷达图和七天行动路径可直接使用。
- 计分与报告在浏览器本地按固定规则生成，不会发起模型调用。
- 报告页支持“个性化建议”：用户主动点击后才调用模型；每份测评结果成功获取后只生成 1 次，同一访客每天最多成功获取 5 次。
- 最近一次结果保存在当前浏览器；清除站点数据后会丢失。
- 个性化建议由 Cloudflare Pages Function 和 D1 提供用量保护；基础测评不依赖模型服务。

## 功能

- **12 道情境选择题**，覆盖 AI 理解与判断、任务表达与协作、场景应用与问题解决、工具选择与流程能力
- **固定规则报告**，根据四维得分展示能力阶段、优势、优先短板和三步行动建议
- **四维雷达图**，直观看到能力结构
- **本地复测**，最近一次结果保存在当前浏览器
- **纯前端**，答完即出结果，无需注册登录
- **可选个性化建议**，按本次四维得分输出自然中文建议，支持标题、列表与加粗；固定报告始终不依赖它

## 架构

```
用户答题 → 前端固定规则计算四维得分 → 立即展示阶段、画像和行动路径

最近一次结果 → localStorage → 刷新后可再次查看

用户主动点击个性化建议
  → Pages Function 按 V2 规则重算结果
  → 大模型按需返回自由 Markdown 文本
  → 前端安全渲染文本，D1 记录本次结果与每日额度

用户在起始页同意匿名数据收集
  → 完成答题后立即展示本地报告
  → Pages Function 按 V2 规则重算结果
  → 飞书 Base 写入匿名测评编号、答案、得分、阶段和时间
```

设计原则：**轻量、国内可访问、成本可控**。核心测评不依赖模型调用，AI 分析按需启用。

## 遇到的问题

| 问题 | 解决方案 |
|------|----------|
| Supabase 域名国内访问不稳定 | 从 Supabase 方案迁移，保留历史实现记录 |

| 模型调用成本需要控制 | 基础报告固定规则生成；模型只在用户主动点击时调用，并由 D1 限制成功次数 |
| 模型名升级 | 适配最新模型版本 |
| 变量名冲突 | supabase 重命名为 supabaseClient |

## 个性化建议配置

V2.1 的固定报告可以直接部署和使用。个性化建议已在页面中启用；首次部署或更换环境时，需要确认以下服务端配置：

1. 在 Cloudflare Pages 绑定 D1 数据库为 `DB`，并执行 `schema.sql` 中的建表语句。
2. 在 Pages 的服务端环境变量中配置 `DEEPSEEK_API_KEY` 和随机生成的 `IP_HASH_SECRET`。
3. 确认 `index.html` 中的 `AI_ANALYSIS_ENABLED` 为 `true` 后重新部署。
4. 验证首次成功、同一结果再次请求、同一 IP 第 6 次请求三种情况是否符合预期。

密钥只存在于 Cloudflare 服务端配置，不能写进前端代码或提交到仓库。未完成以上配置时，页面会明确显示“个性化建议暂未开启”，不影响测评、固定报告和七天行动路径。模型返回的内容不受 JSON、固定段落、字数或 token 上限约束，但页面只安全渲染常用 Markdown，不执行模型返回的 HTML。

飞书知识库陪练属于后续独立版本；当前 V2.1 不接入知识库、登录或聊天问答。

## 匿名测评数据导出

用户必须先在起始页勾选“我已知悉并同意：本次匿名测评数据将用于改进测评。”才能开始答题。完成后，报告会立即在浏览器展示；匿名数据导出在后台进行，失败不会影响测评体验。

导出字段仅包括随机测评编号、同意和完成时间、12 题答案、四维得分、总分、能力阶段和测评版本。不收集姓名、联系方式、IP、设备信息、地理位置、个性化建议全文或自由文本反馈。

Cloudflare Pages 生产环境需要配置以下加密环境变量：

- `FEISHU_APP_ID`
- `FEISHU_APP_SECRET`
- `FEISHU_BASE_TOKEN`
- `FEISHU_ASSESSMENT_TABLE_ID`

这些值只能来自具备 Base 写入权限的飞书自建应用与目标数据表，不能写进前端或提交到仓库。匿名测评数据表与用户主动填写的 `体验反馈` 表保持分离。
