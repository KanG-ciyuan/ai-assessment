# AI 能力测评 — 前端开发 Prompt（v2：极简高级感）

## 产品背景

一款免费开放的 AI 能力测评工具。用户打开网页，完成 12 道选择题，提交后获得 AI 生成的个性化能力分析报告。

---

## 页面结构（2 个页面）

### 页面 1：测评问卷页（/ 首页）

**整体布局**
- 极简，左右分栏：左侧（60%）放题目内容，右侧（40%）放进度指示 + 氛围元素
- 不要导航栏、不要 logo、不堆功能入口

**左侧 — 题目区域**
- 一次只显示 1 道题（一题一翻）
- 题干：大号、深色、加粗，像杂志标题
- 题目编号细字显示在题干上方（如 QUESTION 03 / 12）
- 4 个选项竖向排列，每项是干净的矩形色块
- 默认：浅灰底色（#f5f5f5），圆角 12px
- 选中态：黑底白字，瞬间切换，微缩放 1.02
- 选完后 0.3 秒自动滑到下一题（淡入淡出过渡）
- 支持「上一题」回退

**右侧 — 进度面板**
- 12 个小圆点竖向排列，已答变实心黑、当前题外圈发光、未答浅灰空心
- 圆点旁显示简短标签（如「AI 认知」「使用频率」），标注当前维度
- 底部显示已用时（分:秒），轻量计时不制造紧迫感

**最后一题**
- 答完后卡片底部浮现「查看我的报告」按钮
- 按钮：黑底白字，居中，圆角，hover 微提阴影

---

### 页面 2：结果报告页（/result）

**顶部 — 报告摘要**
- 一句总结（大号深色字体，醒目）
- 总分 + 等级标签
- 等级命名：36-27 探索者 / 26-18 进阶者 / 17-9 入门者 / 8-0 初识者

**中部 — 雷达图**
- SVG 或 Canvas 绘制五边形雷达图
- 填充色：半透明黑 + 细描边
- 加载时从中心展开动画（0.8s）
- 5 个顶点标注维度名

**下方 — 详细分析**
- 按维度展开，每维度一张干净卡片
- 卡片：白底、细阴影（1-2px blur）、圆角 16px
- 维度名 + 等级标签（强项/中等/薄弱）靠左排列
- 分析文本在下方，行间距宽，易读
- 建议列表用圆点 + 短句

**学习路径 — 时间线**
- 竖线 + 三个节点，左右交替排列
- 第一步（立刻做）、第二步（一个月内）、第三步（长期）
- 节点用圆形 + 文字描述

**底部**
- 「重新测评」文字链接
- 极小 Footer 字：「AI 能力测评 · 公益项目 · 作者 KanG」

## 设计风格要求

**配色**
- 背景：纯白 #ffffff 或极浅灰 #fafafa
- 主文字：深黑 #1a1a1a
- 辅文字：中灰 #666666
- 卡片底色：浅灰 #f5f5f5
- 强调色：黑 #000000（用于选中态、按钮、高亮元素）
- 不引入第三种颜色，保持黑白灰极简

**字体**
- 无衬线（Inter 或系统默认）
- 标题大而有力，正文轻而透气
- 行间距 1.6-1.8，不挤

**卡片与阴影**
- 圆角 12-16px
- 阴影极轻：`0 1px 3px rgba(0,0,0,0.04)`，几乎不可见但制造悬浮感
- 不要边框，用背景色差区分层级

**留白**
- 大胆留白，元素间距宽松
- 卡片之间至少 24px 间隔
- 移动端适配后保持比例

**动效**
- 题目切换：淡入淡出 0.3s ease
- 选项选中：瞬间翻转颜色（无过渡，利落）
- 雷达图：0.8s 展开动画
- 按钮 hover：阴影加深 + 微上移 2px
- 页面切换：整体 fade

**移动端**
- 左右分栏改为上下堆叠
- 进度面板缩到顶部横条
- 选项按钮最小高度 48px
- 字体和间距等比例缩小但不失真

## 技术实现

**第一版：纯前端**
- 先不连数据库和 API
- 用户答完 12 题后，前端本地计算各维度得分
- 用预设模板展示报告（3-4 种典型结果按总分匹配）
- 单文件 HTML 或简单 React 项目

**后续升级**
- 接入 Supabase 存答题记录
- 接入 DeepSeek API 生成真实 AI 分析

## 参考风格

- Linear 官网的留白和排版
- Apple 产品页的字体层次
- Stripe 的按钮和交互细腻度
- Vercel 模板的卡片阴影处理

**一句话**：做出来的页面，用户第一眼感觉是「这是一个安静、可信的工具」，不是「又一个花里胡哨的 Demo」。
